# Zeephoria - Perfume Store Landing Page

A static landing page for a perfume store, built with HTML5 and CSS3.

## Features
- Navbar with 8 links, a search box and a dropdown under "blog"
- Hero section with a call-to-action
- "Featured works" gallery of 6 perfume cards
- "What we offer" section with 6 feature boxes
- Pricing table with 3 plans
- Team section (3 members) and news section (3 cards)
- Footer with social media icons

## Live Demo
https://abdelazizessam2277.github.io/Zeephoria/

## Tech Stack
HTML5, CSS3, Font Awesome

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
